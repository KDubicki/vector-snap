# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-02

## Context

Design decisions made at the start of the project need to be traceable for future
contributors.

## Decision

Significant architectural decisions are recorded as short Markdown files in `docs/adr/`,
numbered sequentially (`NNNN-title.md`), using the format: Context, Decision,
Consequences. Superseded ADRs are kept and marked as such.

## Consequences

Decisions are discoverable and reviewable in pull requests together with the code.
